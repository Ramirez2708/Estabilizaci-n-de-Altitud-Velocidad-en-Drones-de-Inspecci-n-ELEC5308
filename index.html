1. Contexto industrial y arquitectura de control

Los drones de inspección se utilizan para revisar techos, puentes, instalaciones eléctricas y estructuras industriales. Para obtener imágenes estables, el dron debe mantener una altura determinada aunque existan cambios de carga o corrientes de aire.

Planta

El movimiento vertical del dron y su estructura.

Sensor

Barómetro o sensor de distancia que mide la altitud.

Controlador

Unidad electrónica que compara la altura medida con la deseada.

Actuador

Motores y hélices que modifican el empuje.

Variable controlada

Altitud vertical del dron, medida en metros.

Perturbaciones

Ráfagas de viento, cambios de carga y variaciones del empuje.

Funcionamiento general

Altura deseada
→
Controlador
→
Motores y hélices
→
Dron (planta)
→
Sensor de altitud

El sensor informa la altura actual. El controlador calcula la diferencia con la altura deseada y ajusta el empuje para reducir ese error.

2. Modelado matemático físico y linealización

Se considera el movimiento vertical del dron. El sentido hacia arriba se toma como positivo. Las fuerzas principales son el empuje de las hélices hacia arriba, el peso hacia abajo y el arrastre del aire, que se opone al movimiento.

Fuerzas del sistema

m · dv/dt = T − mg − c·v|v|

Donde m es la masa (kg), v la velocidad vertical (m/s), T el empuje (N), g la gravedad (9,81 m/s²) y c un coeficiente de arrastre.

La altura cambia según la velocidad:

dh/dt = v

Vuelo estacionario y linealización

En vuelo estacionario el dron mantiene su altura, por lo que la velocidad es cero y el empuje equilibra el peso:

v₀ = 0     T₀ = mg

Se estudian pequeñas variaciones alrededor de ese punto: ΔT es el cambio pequeño de empuje y Δh la variación de altura. Al linealizar el arrastre cuadrático alrededor de v₀ = 0, su efecto de primer orden es cero. Por eso, para este modelo sencillo de pequeñas variaciones:

m · d²(Δh)/dt² = ΔT

Aplicando Transformada de Laplace con condiciones iniciales iguales a cero:

m s² ΔH(s) = ΔT(s)   ⇒   G(s) = ΔH(s)/ΔT(s) = 1/(m s²)

La aproximación es válida cerca del vuelo estacionario. El arrastre cuadrático se presenta en el modelo físico, pero desaparece en la aproximación lineal de primer orden alrededor de velocidad cero.

La altura medida se devuelve al comparador mediante realimentación negativa. El controlador proporcional-derivativo (PD) aumenta o reduce el empuje según el error de altura y la velocidad vertical.

Función de transferencia en lazo cerrado

C(s) = Kp + Kd·s
T(s) = (Kp + Kd·s)/(m·s² + Kd·s + Kp)

Para el análisis, se utilizan valores positivos de masa, Kp y Kd. La conexión invertida cambia el signo de la realimentación y puede producir una respuesta inestable.

Representación en espacio de estados

Se definen los estados x₁ = Δh y x₂ = Δv, con entrada u = ΔT y salida y = Δh:

ẋ = A·x + B·u    y = C·x + D·u
A = [0  1; 0  0]   B = [0; 1/m]   C = [1  0]   D = [0]

El modelo representa la dinámica vertical linealizada alrededor del vuelo estacionario.

5. Análisis de estabilidad y conclusiones de ingeniería

Polos y estabilidad

El denominador de la función de transferencia en lazo cerrado es:

m·s² + Kd·s + Kp = 0

Con masa y ganancias positivas, los polos tienen parte real negativa y la respuesta tiende a estabilizarse. En lazo abierto, la planta tiene dos polos en el origen; por ello, una entrada de empuje constante produce un cambio de altura que sigue creciendo.

Con realimentación invertida, la ecuación característica queda:

m·s² − Kd·s − Kp = 0

Esta conexión tiene un polo positivo y genera una respuesta que se aleja del valor deseado. Por eso es importante conectar correctamente la realimentación negativa.

Teorema del valor final

Para una referencia escalón de 1 metro y un sistema estable con realimentación negativa, el error final ideal es cero y la altura final es:

h(∞) = 1 m

Conclusiones

  • El empuje de las hélices debe compensar el peso para mantener el vuelo estacionario.
  • El sensor permite conocer la altura y el controlador corrige las diferencias con la referencia.
  • La realimentación negativa mejora el mantenimiento de altura frente a cambios y perturbaciones pequeñas.
  • Una conexión invertida puede volver inestable el sistema y provocar que la altura se aleje del valor deseado.
